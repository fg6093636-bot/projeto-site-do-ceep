# Projeto Site CEEP - INFINT2A

Este repositório contém o projeto final da disciplina de Desenvolvimento Web, focado no CEEP Prof.ª Lourdinha Guerra.

## 📋 Requisitos Atendidos
- Uso de tags semânticas (header, main, footer).
- Estilo CSS separado em múltiplos arquivos.
- Design responsivo para dispositivos móveis.
- Formulários com validação, radio buttons e checkboxes.
- Tabelas e listas com dados reais do SIGEduc.

## 🛠️ Tecnologias
- HTML5
- CSS3
- Git/GitHub
